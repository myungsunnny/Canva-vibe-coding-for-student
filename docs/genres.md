# 게임 유형 사전 (Canva Code 한 페이지 웹게임)

`ui-dictionary.html`의 데이터 형식(id, category, koName, enName, tags, description, prompt)을 따르고, 유형 사전에 필요한 키를 추가했습니다.

작성 규칙
- 목록형 값: tags, uiParts는 쉼표(`, `)로, howItWorks, exampleIdeas, upgrade는 ` / `로 구분합니다.
- category: `action`(반응·조작), `puzzle`(퍼즐), `brain`(지식·전략·기억), `story`(이야기·탈출).
- difficulty: Canva Code로 만들기 난이도 (1 쉬움 ~ 5 어려움).
- uiParts는 `ui-dictionary.html`의 koName을 그대로 사용합니다.
- 모든 소재는 폭력·도박·실존 상표 캐릭터 복제를 제외했습니다. 실존 게임은 '~ 스타일'로만 표기합니다.

UI 사전 koName 목록: 헤드업 디스플레이 (허드), 체력 게이지 (HP 바), 스킬 슬롯 & 쿨타임, 데미지 플로터 (전투 텍스트), 조준점 (크로스헤어), 미니맵 & 레이더, 대화창 (다이얼로그 박스), 인벤토리 & 그리드 슬롯, 가상 조이스틱 (컨트롤 패드), 알림 배너 & 퀘스트 트래커, 경험치 바 & 레벨 표시, 게임 오버 / 결과 모달창

---

### runner-jump
- category: action
- koName: 러너 · 점프 게임
- enName: Runner / Jump Game
- tags: 점프, 장애물, 최고기록
- description: 캐릭터가 앞으로 달리거나 날아가는 동안 장애물을 피해 점프하는 게임입니다. 타이밍을 맞추는 것이 가장 중요해서 처음 만들기에 좋습니다.
- howItWorks: 아무것도 누르지 않으면 캐릭터가 중력 때문에 아래로 내려갑니다. / 화면을 누르거나 스페이스바를 누르면 위로 점프합니다. / 장애물에 닿으면 끝나고, 장애물 하나를 지날 때마다 점수가 올라갑니다.
- difficulty: 2
- exampleIdeas: 알파벳 기둥 사이를 날아가는 종이비행기 / 쓰레기를 피해 달리는 지구 지킴이 / 플래피 버드 스타일의 우리 반 마스코트 날기
- uiParts: 헤드업 디스플레이 (허드), 게임 오버 / 결과 모달창, 가상 조이스틱 (컨트롤 패드)
- prompt: 초등 고학년이 즐길 수 있는 한 페이지 점프 게임을 만들어줘. 주인공은 우리 반 마스코트로 내가 정한 동물 캐릭터야. 스페이스바나 화면 터치를 하면 위로 점프하고, 누르지 않으면 중력으로 천천히 떨어져. 위아래에서 기둥 장애물이 오른쪽에서 왼쪽으로 계속 움직여. 장애물 하나를 통과할 때마다 1점을 올리고, 장애물이나 바닥에 닿으면 게임이 끝나. 점수는 화면 위쪽에 크게 보여주고, 끝나면 최고 점수와 다시 시작 버튼을 보여줘. 디자인은 밝은 파스텔 색의 귀여운 스타일로 해줘. 이름, 학교, 전화번호, 사진 같은 개인정보는 게임 안에 넣지 말아줘.
- upgrade: 점수 10점마다 속도를 조금씩 빠르게 하기 / 코인 아이템을 먹으면 보너스 점수 받기
- caution: 유명 게임의 캐릭터와 그림은 그대로 쓰지 말고 내가 직접 만든 캐릭터를 사용합니다.

### space-shooter
- category: action
- koName: 우주 슈팅 게임
- enName: Space Shooter
- tags: 발사, 조종, 점수
- description: 우주선을 좌우로 움직이며 하늘에서 내려오는 운석을 레이저로 치우는 게임입니다. 키보드 입력과 충돌 판정을 배우기 좋습니다.
- howItWorks: 좌우 방향키로 우주선을 움직이고 스페이스바로 레이저를 발사합니다. / 운석이 위에서 계속 내려오고, 레이저가 맞으면 운석이 사라지며 점수가 올라갑니다. / 운석이 우주선에 닿으면 생명이 줄고, 생명이 0이 되면 끝납니다.
- difficulty: 3
- exampleIdeas: 우주 쓰레기를 치우는 청소 로봇 / 바닷속 오염물질을 치우는 잠수함 / 지구로 떨어지는 소행성을 막는 방어 위성
- uiParts: 체력 게이지 (HP 바), 헤드업 디스플레이 (허드), 조준점 (크로스헤어), 게임 오버 / 결과 모달창
- prompt: 초등 고학년과 중학생이 즐길 수 있는 우주 청소 슈팅 게임을 만들어줘. 주인공은 내가 만든 청소 우주선이고 좌우 방향키로 움직여. 스페이스바를 누르면 레이저가 위로 발사돼. 운석은 위에서 무작위 위치로 내려오고, 레이저에 맞으면 사라지면서 10점을 줘. 운석이 우주선에 닿으면 생명 하트가 하나 줄고, 하트가 3개 모두 없어지면 게임이 끝나. 점수와 남은 생명은 화면 위쪽에 보여주고, 끝나면 최종 점수와 다시 시작 버튼을 보여줘. 디자인은 어두운 우주 배경에 네온 색 우주선으로 만들어줘. 이름, 학교, 전화번호, 사진 같은 개인정보는 넣지 말아줘.
- upgrade: 3점 연속 명중하면 레이저가 두 줄로 나가는 파워업 추가하기 / 점수가 올라갈수록 운석이 더 빨리 내려오는 레벨 만들기
- caution: 적은 운석·쓰레기 같은 사물로 하고, 사람이나 동물을 공격하는 장면은 넣지 않으며 유명 우주선 디자인을 베끼지 않습니다.

### whack-a-mole
- category: action
- koName: 반응속도 게임 (두더지 잡기)
- enName: Whack-a-Mole / Reaction Game
- tags: 반응속도, 클릭, 제한시간
- description: 구멍에서 불쑥 나타나는 목표를 빠르게 눌러서 점수를 얻는 게임입니다. 제한시간과 무작위 위치를 배우기 좋습니다.
- howItWorks: 3×3 구멍 중 무작위로 한 곳에서 목표가 올라옵니다. / 목표가 사라지기 전에 누르면 점수를 얻고, 놓치면 점수가 없습니다. / 30초 제한시간이 끝나면 최종 점수를 보여줍니다.
- difficulty: 1
- exampleIdeas: 영어 단어 카드 두더지 잡기 / 정답 숫자만 누르는 곱셈 두더지 / 재활용품만 골라서 누르기 (다른 것은 감점)
- uiParts: 헤드업 디스플레이 (허드), 알림 배너 & 퀘스트 트래커, 게임 오버 / 결과 모달창
- prompt: 초등 고학년이 즐길 수 있는 반응속도 게임을 만들어줘. 화면에 3×3 구멍이 있고 무작위로 한 구멍에서 귀여운 캐릭터가 나타났다 1초 뒤에 사라져. 마우스나 터치로 캐릭터를 누르면 10점을 얻고 반짝이는 효과를 보여줘. 제한시간은 30초이고 위쪽에 남은 시간과 점수를 보여줘. 시간이 끝나면 최종 점수와 다시 시작 버튼을 보여줘. 디자인은 잔디밭 배경의 밝고 귀여운 스타일로 해줘. 이름, 학교, 전화번호, 사진 같은 개인정보는 넣지 말아줘.
- upgrade: 눌러서는 안 되는 방해 캐릭터를 섞어 누르면 감점하기 / 시간이 갈수록 캐릭터가 더 빨리 사라지게 하기
- caution: 때리는 느낌 대신 '콕 눌러 잡기' 표현을 쓰고, 두더지 같은 흔한 캐릭터라도 기존 게임의 그림을 그대로 쓰지 않습니다.

### snake-arcade
- category: action
- koName: 스네이크형 아케이드
- enName: Snake-style Arcade
- tags: 방향키, 성장, 격자
- description: 방향키로 길쭉한 캐릭터를 움직이며 먹이를 먹고 점점 길어지는 게임입니다. 격자 위의 움직임과 충돌 규칙을 배우기 좋습니다.
- howItWorks: 방향키로 이동 방향을 바꾸면 캐릭터가 격자 칸을 따라 계속 움직입니다. / 먹이를 먹으면 몸이 한 칸 길어지고 점수가 올라갑니다. / 벽이나 자기 몸에 닿으면 게임이 끝납니다.

- prompt: 초등 고학년이 즐길 수 있는 스네이크 스타일 게임을 만들어줘. 20×20 격자판 위에서 기차 모양 캐릭터가 계속 앞으로 움직이고 방향키로 방향을 바꿔. 과일이 무작위 칸에 하나씩 나타나고, 먹으면 기차가 한 칸 길어지며 10점을 얻어. 벽이나 자기 몸에 부딪히면 게임이 끝나. 점수는 위쪽에 보여주고, 끝나면 최고 점수와 다시 시작 버튼을 보여줘. 모바일에서도 할 수 있게 화면에 방향 버튼 4개를 넣어줘. 디자인은 깔끔한 레트로 픽셀 스타일로 해줘. 이름, 학교, 전화번호, 사진 같은 개인정보는 넣지 말아줘.
- upgrade: 속도를 선택하는 난이도 버튼(쉬움·보통·어려움) 만들기 / 가끔 나타나는 보너스 별을 먹으면 20점 얻기
- caution: 유명 모바일 게임의 이름과 캐릭터를 그대로 쓰지 않고 나만의 캐릭터를 사용합니다.

### tower-defense
- category: action
- koName: 타워 디펜스
- enName: Tower Defense
- tags: 전략, 배치, 웨이브
- description: 길을 따라 오는 방해꾼을 막기 위해 방어 도구를 알맞은 곳에 놓는 게임입니다. 어디에 무엇을 놓을지 생각하는 전략이 중요합니다.
- howItWorks: 정해진 길을 따라 방해꾼이 입구에서 출구로 움직입니다. / 코인으로 길 옆 칸에 방어 도구를 설치하면 사거리 안의 방해꾼을 자동으로 공격합니다. / 방해꾼이 출구에 닿으면 체력이 줄고, 체력이 0이 되면 끝납니다.
- difficulty: 5
- exampleIdeas: 먼지 구름에게서 교실 지키기 / 잡초를 막아 학교 텃밭 지키기 / 쓰레기 로봇에게서 바다 지키기
- uiParts: 체력 게이지 (HP 바), 인벤토리 & 그리드 슬롯, 알림 배너 & 퀘스트 트래커, 스킬 슬롯 & 쿨타임
- prompt: 중학생이 만들 수 있는 한 페이지 타워 디펜스 게임을 만들어줘. 화면에는 구불구불한 길이 있고 먼지 구름이 입구에서 출구로 천천히 움직여. 아래 도구 바에서 물총 타워를 골라 길 옆 빈 칸을 눌러 설치할 수 있고, 타워는 사거리 안의 먼지 구름을 자동으로 맞혀. 구름을 없앨 때마다 코인 5개를 얻고, 타워 설치에는 코인 20개가 필요해. 구름이 출구에 닿으면 교실 체력이 1 줄고, 체력 10이 모두 없어지면 게임이 끝나. 3번의 웨이브로 나누어 점점 구름 수를 늘리고, 모두 막으면 승리 화면을 보여줘. 디자인은 밝은 교실 그림 스타일로 해줘. 이름, 학교, 전화번호, 사진 같은 개인정보는 넣지 말아줘.
- upgrade: 타워를 눌러 공격력을 올리는 업그레이드 기능 추가하기 / 느리게 하는 타워 등 두 번째 종류의 타워 만들기
- caution: 방어 대상은 사물이나 자연으로 하고, 사람이나 동물을 해치는 설정은 쓰지 않으며 유명 게임의 타워·몬스터 그림은 베끼지 않습니다.

### sliding-puzzle
- category: puzzle
- koName: 슬라이딩 퍼즐
- enName: Sliding Puzzle
- tags: 퍼즐, 조각 맞추기, 이동 횟수
- description: 섞인 조각을 한 칸씩 밀어서 올바른 순서로 맞추는 퍼즐입니다. 규칙은 단순하지만 어떻게 밀지 생각해야 합니다.
- howItWorks: 3×3 판에 숫자 조각 8개와 빈칸 1개가 섞여 있습니다. / 빈칸 옆에 있는 조각을 누르면 빈칸으로 이동합니다. / 1부터 8까지 순서대로 맞추면 성공이고 이동 횟수를 기록합니다.
- difficulty: 3
- exampleIdeas: 우리 학교 마스코트 그림 맞추기 / 한국 지도 조각 맞추기 / 역사 인물 연표 카드 순서 맞추기
- uiParts: 헤드업 디스플레이 (허드), 알림 배너 & 퀘스트 트래커, 게임 오버 / 결과 모달창
- prompt: 초등 고학년이 즐길 수 있는 슬라이딩 퍼즐 게임을 만들어줘. 3×3 판에 숫자 조각 1~8과 빈칸 하나가 있고 시작할 때 항상 풀 수 있는 상태로 섞어줘. 빈칸 옆의 조각을 누르면 빈칸으로 한 칸 움직여. 위쪽에 이동 횟수와 경과 시간을 보여주고, 1부터 8까지 순서대로 맞추면 '성공' 화면과 기록을 보여줘. 섞기 버튼과 처음부터 버튼도 넣어줘. 디자인은 둥근 모서리의 파스텔 색 조각으로 해줘. 이름, 학교, 전화번호, 사진 같은 개인정보는 넣지 말아줘.
- upgrade: 판 크기를 3×3, 4×4로 고르게 하기 / 숫자 대신 내가 직접 그린 그림 조각으로 바꾸기
- caution: 그림 조각은 직접 만든 그림이나 이용 조건을 확인한 이미지만 쓰고, 사람 얼굴 사진은 쓰지 않습니다.

### match-three
- category: puzzle
- koName: 매치 퍼즐 (같은 그림 맞추기)
- enName: Match-Three Puzzle
- tags: 같은 그림, 연쇄, 점수
- description: 같은 모양 세 개 이상을 가로나 세로로 나란히 맞춰 없애는 퍼즐입니다. 한 번에 많이 없앨수록 점수가 커집니다.
- howItWorks: 격자판에 여러 모양의 블록이 채워져 있고, 이웃한 두 블록을 서로 바꿀 수 있습니다. / 같은 모양이 3개 이상 이어지면 사라지고, 위의 블록이 아래로 내려와 빈칸이 채워집니다. / 제한된 이동 횟수 안에 목표 점수를 넘으면 성공합니다.
